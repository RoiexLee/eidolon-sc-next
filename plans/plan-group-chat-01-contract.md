# 群组对话票 01：术语与领域契约

Status: draft

本票只建立群组对话的正式词汇和架构边界，为后续数据层与文字纵切提供不变的契约；不实现代码。

## 已确认决策

- 正式领域术语是「群组对话」，并与现有单角色「对话」区分；「群聊」不作为正式名称。
- 一条群组对话首期有 **2–5 位当前成员**，成员有稳定顺序；移除成员保留历史作者，不再参与之后的目标选择。
- 首期文字回合只接受 **一位明确目标的当前成员**。没有唯一目标、目标已移除或目标不属于该群组时拒绝，不随机唤起多人。
- 「角色模型」在群组语境中只指角色的 **音色、头像和立绘**；扮演 LLM 仍是部署级配置，不为每位角色新增独立模型。
- 群组通话是文字协议稳定后的独立阶段；需要 speaker 事件、成员快照和音色切换，首票不改单角色通话。
- 群组数据包 **不要求首期支持导出**。后续票决定格式、迁移和未支持时的明确阻止方式，不能静默丢数据。

## 本票交付物

- 在 `GLOSSARY.md` 增加群组对话、群组成员、群组头像、群组消息、群组回合和群组通话的定义，并注明与单角色术语的边界。
- 新增 [ADR-0029](../docs/adr/0029-group-conversations-are-independent.md)，记录群组独立实体、首期单目标文字回合、角色模型含义、通话后置和数据包决策。
- 保持旧 `Conversation`、`Call`、单角色消息和既有 API 的语义不变；后续实现票按本票术语命名。

## 不在本票范围内

- 数据库、后端路由、SSE、前端页面、模型调用和群组通话实现。
- 群组轮流回复、主动接话、好感度、记忆、统计、成就和单角色能力的迁移。
- 群组数据包导出/导入格式和实现。

## 验收

- 词汇表中的六个群组术语与 ADR-0029 使用同一套边界和名称。
- 计划和 ADR 明确写出 2–5 位当前成员、首期单目标文字、角色模型三项含义、通话后置和首期不要求数据包导出；词汇表只保持「数据包」的既有通用定义，不承载实现策略。
- 文档差异通过 `git diff --check`，本票不运行实现测试。
